# Neo Windows 0.2.9

状态：2026-11-17 20:18（UTC+9）已公开发布为 GitHub 最新正式版 `v0.2.9`。19:48 最终构建已通过本机实际覆盖升级、自动冷启动、原节点联网和正常退出清理验收；上传的三个资产均已与本地文件核对大小及 GitHub 服务端 SHA-256。本机内部验收记录不入库，公开验证范围见本页。

发布地址：https://github.com/lubenwei-lian/neo/releases/tag/v0.2.9

## 内核更新

- 统一 Xray、sing-box、mihomo、Naive 的下载、校验和安装流程。
- 已连接 Neo 时只尝试本机 SOCKS5 / HTTP 代理；代理失败明确报错并保留断点，不再静默回退直连。未连接时仍支持直连及系统代理。
- 更新弹窗持续显示下载量、进度、速度和安装阶段，避免慢速下载时无反馈；超过两分钟的下载继续等待真实结果。
- 修复续传范围不符、过期断点返回 HTTP 416 和响应头无限等待的问题。
- 安装前要求官方 SHA-256，校验完整内核版本，并对适用的当前配置进行预检。
- sing-box 与配套 libcronet.dll 一起更新、一起回滚；安装中断保留恢复记录。
- 文件替换等待旧内核真正退出，只恢复本次更新暂停的同一节点。下载期间用户主动断开或选点时不覆盖用户意图。
- 修复更新后设置页版本未刷新的问题。
- 连接页、设置页及更新检查共用版本缓存；手动检查重新探测实际可执行文件，修复版本长期显示未知或读到空值的问题。
- 已是最新或本地版本更高时不再提供安装按钮；区分“未安装”和“已安装但版本读取失败”，避免误报更新和重复安装。
- 检查软件和内核更新时立即显示持续旋转的等待指示；请求完成、失败或超时后恢复按钮，防止重复检查，切换设置分组不会丢失等待状态。

## 安装升级

- 安装包升级保留用户已经更新的内核及配套 libcronet.dll，避免新 exe 配回旧 DLL。
- 保留订阅、手选节点、设置和用户数据。
- 默认打包内核继续沿用已用版本 Xray 26.10.21 / sing-box 1.14.3；用户可在设置中检查更新。安装包不强制替换现有内核。

## 连接与 TUN

- 开关 TUN 改为独立接管层切换，保留当前手选节点、主节点内核进程、连接计时和流量历史，不再为切换模式重新连接节点。
- TUN 启动失败或接管层异常退出时，保留原节点代理会话；接管层单独进行一次恢复，失败后回退到普通代理模式。
- 修复本机内核监听端口被 Windows 拒绝时无法启动的问题；仅对已确认的本地监听绑定失败尝试一次备用端口，不把远端连接失败误判为端口冲突。
- 孤儿代理清理改为读取本机 TCP 监听表，避免 IPv6 回环连接被系统策略拒绝时误清仍在使用的代理。无法确认端口归属时保留设置并记录原因。
- 修复 TUN 保留系统代理后，连接页面仍错误显示“未接管”的问题；显示以 Windows 实际代理状态为准。
- 关闭 TUN 会撤销系统接管路由，应用通过 TUN 建立的既有长连接仍可能需要自行重建；保留节点会话不代表所有应用连接均无中断。

## 启动

- 修复隐藏窗口等待动画帧、动画帧又等待窗口显示的启动循环；保留正常的双帧显示路径，并为隐藏 WebView 增加只触发一次的就绪通知后备路径。
- 最终安装包实测无需手动显示窗口即可自动打开，首次界面就绪约 2.9 秒；启动到托盘及隐藏后恢复也已检查。
