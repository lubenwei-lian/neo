# Neo Windows 节点与订阅支持

更新：2026-11-16。以下为本项目已经接入的配置和运行路径，不把内核的全部能力等同于客户端支持。

## 节点

| 协议 | 导入方式 | 承载 |
|---|---|---|
| VMess / VLESS / Trojan | 分享链接、Clash | Xray 或 sing-box，按具体传输与安全参数选择 |
| Shadowsocks | SIP002 分享链接、SIP008、Clash | Xray / sing-box；SIP003 插件按 sing-box 路径 |
| ShadowsocksR | `ssr://`、Clash SSR | sing-box 前置 + mihomo 辅助协议进程 |
| Hysteria2 | `hysteria2://` / `hy2://`、Clash | sing-box |
| TUIC | `tuic://`、Clash | sing-box |
| AnyTLS | `anytls://`、Clash | sing-box |
| SOCKS5 | `socks://` / `socks5://`、Clash | Xray / sing-box |
| HTTP / HTTPS 代理 | 带认证信息的 `http://user:pass@host:port` / `https://...`、Clash | Xray / sing-box |
| WireGuard | `wireguard://`、`.conf`、Clash | sing-box endpoint |
| Naive HTTPS / QUIC | `naive+https://` / `naive+quic://` | sing-box 前置 + naive 辅助协议进程 |

Hysteria v1 不会错误映射成 Hysteria2。整份 Clash 配置仍可交给 mihomo 解析其支持的配置。SSR 的加密、协议和混淆必须为内置 mihomo 支持的组合，连接前以实际内核校验为准。Naive QUIC 是 UDP 传输，快速 TCP 不会为其显示虚假的 TCP 延迟。

## 订阅与导入

- 远程 HTTP / HTTPS 订阅。
- 多行分享链接，Base64 编码内容和双层 Base64。
- Clash YAML、SIP008 JSON、WireGuard 配置、完整 Xray / sing-box JSON。
- 节点页“更多”→“粘贴节点／配置”或“从文件导入”。
- 订阅页“添加订阅”支持完整本地路径，也可从文件导入；之后刷新会重新读取原文件。

粘贴导入内容保存在本地导入目录，文件导入保留原文件路径。单次上限16 MB。首次订阅自动启用，已有订阅时新增项默认停用，由用户在订阅页启用；导入不切换当前手选节点。重复导入同一来源不创建重复订阅、不改启用状态。导入与刷新共享事务门，避免缓存互相覆盖。

## TUN 和整份配置

普通节点保持现有连接路径。Xray 专有传输（如 XHTTP、mKCP）及 Xray 完整配置在 TUN 下由 Xray 保留原有协议，sing-box 提供 TUN 接入。Clash 完整配置在 TUN 下同样由 sing-box 接入，mihomo 自己的 TUN 与额外监听入口关闭，避免两个接管者。

整份配置的原路由交由其协议内核；前置不再叠加 Neo 的国内绕过、广告规则和游戏直连。辅助进程的精确可执行文件路径在前置 TUN 中直连，防止它的远端连接再次被代理捕获。系统代理、统计与本地用户入口统一归主会话管理。

辅助进程退出会撤销当前会话和代理；开启“内核异常退出后自动重启”时只尝试原节点，不自动选择其他节点。正常断开、取消启动和退出会回收主进程、辅助进程及运行配置。

## 测速和出口检测

普通独立节点可进行真实延迟和出口检测，SSR / Naive 也有独立协议内核路径。整份 Clash / 自定义配置包含自己的路由、选择器和多出口，不把它当作单个确定节点批量测速。

Xray / sing-box 批量出口探针为每个节点分配独立回环入口，入口仅路由到对应节点；未匹配流量拒绝，不借用当前连接的出口。HTTPS trace 必须返回有效公网 IP 和地区才算确认。成功结果复用，失败可补测；升级迁移保留旧成功结果，清除旧“不支持”失败缓存。

## 验证边界

自动检查包括实际内核配置校验、SSR origin/plain + AES-128-CFB 加密回环转发、Xray XHTTP + sing-box 隔离 TUN 前置实际转发、批量入口隔离、导入事务与选中节点保护、辅助进程崩溃/取消/过期回调清理。隔离 TUN 不开启默认路由，不接管用户当前连接。

Hysteria2 和 VLESS 另用本机已有真实节点验证出口；缺少真实服务端的协议不能据此声称已完成公网长稳验收。Naive HTTPS/QUIC 验证实际内核启动、本机监听及退出回收，不把本机监听成功当作远端服务可用。
