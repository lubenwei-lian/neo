neo — 使用说明
========================================

【这是什么】
neo 是 Windows 上的本地代理客户端，内置 xray + sing-box 双内核，
支持订阅导入、系统代理 / TUN 模式、节点测速、自动故障转移、
Clash 订阅直通、自定义配置直通、WireGuard，以及按需安装的 mihomo / naive 内核。

【怎么启动】
双击桌面「neo」图标，或从开始菜单打开。
启动后常驻系统托盘；左键点托盘图标或再次双击 neo 图标可唤出主窗口，
右键托盘图标可连接 / 断开 / 退出。
如果在 设置 → 通用 打开「启动时最小化到托盘」，开机自启时可以静默运行、不弹主窗口。

【订阅链接在哪里配置】
1. 打开主窗口，进入左侧「订阅」页
2. 点「添加订阅」，把机场的订阅链接粘贴进去
3. 点该订阅的「更新」，节点会自动出现在「节点」页
支持一次添加多个订阅。除了常见分享链接（vmess / vless / trojan / ss /
hysteria2 / tuic / anytls / socks5 / wireguard），还支持：
  · Clash 订阅：会额外生成一个「Clash 直通」节点，整份 Clash 配置交给 mihomo 跑；
  · 自定义配置：订阅内容若是整份 xray / sing-box JSON，会生成「自定义配置」节点
    （sing-box 格式支持 TUN；xray 格式不支持 TUN）。

【连接与端口】
· 连接模式：系统代理（默认）或 TUN（需要管理员权限，创建虚拟网卡接管全部流量）。
· 本地端口：设置 → 内核 里可修改 SOCKS / HTTP 端口（默认 21808 / 21809）。
  改完点「应用」会自动重载内核；端口被其他程序占用时会直接提示。
· 分流：默认绕过局域网/大陆、拦截常见广告；「规则」页可自定义分流规则。
· 故障转移：节点失联会自动切到同地区可用节点（托盘气泡会提示）。

【可选内核（设置 → 内核）】
· xray / sing-box 随安装包内置，可在设置里检查更新（下载有进度条、断点续传、
  SHA-256 校验，不会弹窗打断）。
· mihomo：跑「Clash 直通」节点需要；未安装时可在设置里一键下载。
· naive：naive 节点需要；同样按需下载（只作为辅助进程，前置由 sing-box 承载）。
· 内核连续崩溃时看门狗会有限次自动重启；仍失败会停止重启并在状态条/托盘提示。

【一键 WARP】
节点页工具栏「WARP」会向 Cloudflare 注册一个免费 WARP 账号并生成 WireGuard 节点。
它是免费共享出口，速度和可访问站点受地区/策略影响，适合作为没有自建 WG 服务端时的补充。

【备份与恢复】
设置 → 排障：
· 「导出配置」把订阅/节点/规则/用量/自定义配置打成 zip；
· 「导入配置」从备份恢复（会先自动留一份回滚副本，导入后重启应用生效）。

【安全模式】
如果上次启动检测到内核异常，neo 会自动关闭 TUN / 固定出口并在主窗口顶部显示
安全模式横幅；确认不再复现后可在 设置 里恢复之前的设置。

【用户配置和数据在哪里】
全部在根目录的 data 文件夹里：
  state.json               全部设置（端口、连接模式、主题、选中的节点等）
  subscription-cache.json  订阅内容缓存（断网也能看到上次的节点）
  usage.json               流量统计
  custom\                  自定义配置直通保存的 JSON
  clash\                   Clash 直通保存的 YAML
  naive\、mihomo\         对应内核的运行时配置（自动生成）
  backup-preimport-*\      配置导入前的回滚副本
  logs\                    运行日志（排查问题时可用）
想备份或迁移：把整个 data 文件夹拷走即可。
卸载时选择「保留用户数据」，data 文件夹会原样保留。

【文件结构】
  neo.exe      启动入口（双击它；它负责拉起 app\neo.exe）
  app\         程序本体和运行库（请勿改动或删除）
    runtime\   内核与分流数据：xray.exe / sing-box.exe / geoip.dat / geosite.dat /
               rule-sets\ / wintun.dll / libcronet.dll（请勿改动或删除）
               可选内核（按需安装）：mihomo.exe / naive.exe
  data\        你的配置和数据（可随意备份、迁移）
  说明.txt     本文件

【常见问题】
· 首次运行提示“Windows 已保护你的电脑”？
  程序未购买代码签名证书，属正常现象：点「更多信息 → 仍要运行」。
· TUN 模式提示需要管理员权限？
  创建虚拟网卡必需，点「是」即可（之后会自动重连）。
· 修改端口后连不上？
  先确认新端口没有被其他程序占用；被占用时设置页会直接提示，换一个端口即可。
· 杀毒软件误报？
  代理类工具常见误报，可将安装目录加入白名单。
· 连不上 / 节点测速失败？
  先在「订阅」页更新订阅，或在「节点」页重新测速；
  系统代理模式失败时可切换 TUN 模式重试。WARP 节点部分站点不可达属免费出口限制。
· 内核更新中途取消/断网了？
  已下载部分会保留，下次点同一个更新按钮会断点续传；下载完成后会自动校验 SHA-256。
