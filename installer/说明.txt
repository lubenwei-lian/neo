neo — 使用说明
========================================

【这是什么】
neo 是 Windows 上的本地代理客户端（xray + sing-box 双内核），
支持订阅导入、系统代理 / TUN 模式、节点测速、自动故障转移等。

【怎么启动】
双击桌面「neo」图标，或从开始菜单打开。
启动后常驻系统托盘；右键托盘图标可连接 / 断开 / 退出。

【订阅链接在哪里配置】
1. 打开主窗口，进入左侧「订阅」页
2. 点「添加订阅」，把机场的订阅链接粘贴进去
3. 点该订阅的「更新」，节点会自动出现在「节点」页
（支持添加多个订阅；导入的节点在「节点」页点击即可选中并连接）

【用户配置和数据在哪里】
全部在根目录的 data 文件夹里：
  state.json               全部设置（连接模式、主题、选中的节点、开机自启等）
  subscription-cache.json  订阅内容缓存（节点列表来源，断网也能看到上次的节点）
  usage.json               流量统计（今日 / 累计）
  测速缓存                  各节点上次测出的延迟
  logs\                    运行日志（排查问题时可用）
想备份或迁移：把整个 data 文件夹拷走即可。
卸载时选择「保留用户数据」，data 文件夹会原样保留。

【文件结构】
  neo.exe      启动入口（双击它；它负责拉起 app\neo.exe）
  app\         程序本体和运行库（请勿改动或删除）
    runtime\   内核与分流数据：xray.exe / sing-box.exe / geoip.dat / geosite.dat /
               rule-sets\ / wintun.dll / libcronet.dll（请勿改动或删除）
  data\        你的配置和数据（可随意备份、迁移）
  说明.txt     本文件

【常见问题】
· 首次运行提示“Windows 已保护你的电脑”？
  程序未购买代码签名证书，属正常现象：点「更多信息 → 仍要运行」。
· TUN 模式提示需要管理员权限？
  创建虚拟网卡必需，点「是」即可（之后会自动重连）。
· 杀毒软件误报？
  代理类工具常见误报，可将安装目录加入白名单。
· 连不上 / 节点测速失败？
  先在「订阅」页更新订阅，或在「节点」页重新测速；
  系统代理模式失败时可切换 TUN 模式重试。
